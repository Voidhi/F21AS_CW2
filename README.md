# F21AS_CW2 - CoffeeProject

Welcome to the second stage of our application.

This application reads a list of inputs in a csv file and create the according available items for a coffee shop. A user is then able to order mutliple items and generate a bill. A total report with the informations of all orders is generated when the program is closed.
On the second interface, you can see a thread-safe simulation of the queue.
